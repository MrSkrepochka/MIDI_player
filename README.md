# Тактильный семитоновый синтезатор на Nema 17

Данный репозиторий содержит материалы по разработке тактильного семитонового синтезатора на шаговых двигателях Nema 17. Здесь хранятся чертежи установки, функциональные схемы, перечень необходимых компонентов, CAD-модели используемых деталей и описание процесса сборки проекта.

## Описание функционала

Устройство на основе 7 шаговых двигателей Nema 17, закреплённых на деревянной резонирующей панели. Управление реализовано по распределённой схеме: WeMos D1 Mini (ESP8266) отвечает за WiFi-связь и приём MIDI-команд, а STM32F411 выполняет роль вычислительного ядра и управляет драйверами A4988 через две платы CNC Shield V3.

Это открывает следующие возможности:
- воспроизведение MIDI-мелодий в тактильном виде (вибрация по нотам);
- управление со смартфона по WiFi;
- автономное воспроизведение встроенных композиций (не менее 5);
- в перспективе — локальное управление с экрана и кнопок.
